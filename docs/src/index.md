Welcome to HOPE Live Dashboard.

## Available Dashboards

The HOPE Live application provides several interactive dashboards to visualize and analyze data:

### Financial Dashboard
Provides an overview of financial information and spending.
* **Metrics**: Total Amount Paid, Number of Payments, Outstanding Payments.
* **Charts**: Spending Timeline, Delivery Types, Regions, Distribution by Sector, Countries, Distribution by Program, and Financial Service Providers (FSP).

### Demographic Dashboard
Displays a breakdown of Individuals, Households, Children, and Persons with Disabilities (PWD) reached.
* **Metrics**: Individuals Reached, Households Reached, Children, PWD Reached.
* **Charts**: Reach Timeline, Individuals by Sector, Children by Sector, Top Countries (Individuals), and Top Countries (PWD).

### Completion Rate Dashboard
Tracks payment reconciliation and completion statuses.
* **Metrics**: Reconciled Payments, Still Opened.
* **Charts**: Reconciliation Timeline and Number of Payments by Country.

### Grievance Dashboard
Provides an overview of feedback and grievance tickets.
* **Metrics**: Total Tickets.
* **Charts**: Tickets Timeline, Status, Priority, Category, Issue Type, and Tickets by Country.
